## Engagement

- Mode: delivery / coaching / audit / design

Mode declares what this engagement is permitted to produce, not what it is permitted to touch: `delivery` performs authorized work, `coaching` develops the engineer and records a [`COACHING_SESSION.md`](COACHING_SESSION.md), `audit` inspects without mutating, `design` proposes without mutating. Record the level here while the task is being scoped, and every meaningful movement in the handoff, because "the agent did it" and "I read the diff myself" are different claims about the same delivery.
